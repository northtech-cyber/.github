## 🚀 Começa aqui (cerca de 20 minutos)

Segue os passos **por ordem**. Não precisas de instalar nada: tudo se faz no browser.

### ✅ Passo 1 — Cria a tua conta no GitHub

Se ainda não tens: [github.com/signup](https://github.com/signup)

> 💡 Escolhe um **username profissional** (ex.: `ana-silva`, `joaomendes-sec`). Vai aparecer no teu CV e no LinkedIn.

### ✅ Passo 2 — Cria o teu portfólio a partir do nosso template

1. Clica aqui: 👉 **[Criar o meu portfólio](https://github.com/new?template_name=template-portfolio-cyber&template_owner=northtech-cyber)**
2. Em **Owner**, escolhe **a tua conta** (não a organização).
3. Em **Repository name**, escreve: `cyber-journey`
4. Escolhe **Public**.
5. Clica em **Create repository**.

Pronto: tens o teu portfólio em `github.com/<teu-username>/cyber-journey`. É **teu** para sempre, mesmo depois de terminares o programa.

### ✅ Passo 3 — Apresenta-te no README

1. No teu `cyber-journey`, abre o ficheiro `README.md`.
2. Clica no ícone do **lápis ✏️** (canto superior direito do ficheiro).
3. Troca `[O Teu Nome]` pelo teu nome e preenche a secção **"Sobre mim"**: quem és, de onde vens e porque queres trabalhar em cibersegurança.
4. Clica em **Commit changes…** → **Commit changes**.

### ✅ Passo 4 — Dá acesso ao teu mentor

No teu `cyber-journey`: **Settings → Collaborators → Add people** → escreve `W4cher` → **Add**.

Assim o mentor pode rever o teu trabalho e comentar diretamente.

### ✅ Passo 5 — Começa a Fase 0

Lê o [Código de Conduta](https://github.com/northtech-cyber/cyber-base/blob/main/CODIGO-DE-CONDUTA.md) e abre a [**Fase 0 — Preparar o Laboratório e Ética**](https://github.com/northtech-cyber/cyber-base/blob/main/fases/fase-00-laboratorio-e-etica.md). Nela vais montar o teu laboratório e fazer o teu **primeiro Pull Request**.

### ✅ Passo 6 — Envia o link ao mentor

Manda ao mentor o link do teu portfólio (`github.com/<teu-username>/cyber-journey`). Está feito! 🎉

## 📅 Como funciona cada semana

| Dia | O que fazes |
|---|---|
| **Segunda** | Exercício do primeiro dia da fase |
| **Terça a quinta** | Exercícios e perguntas do mentor, na issue da fase |
| **Sexta e sábado** | Mini-projeto, publicado no teu `cyber-journey` |
| **Domingo** | Apresentação do mini-projeto ao mentor (5 a 10 min) |

**Carga sugerida:** 8 a 10 horas por semana. Uma fase só termina quando o mini-projeto estiver **entregue e apresentado**.
